## 2. 文档要点（法典口径）

- **§0.6.1 双模式**：清单为空 = `VIBE`（自由模式，"无合同门槛，但碰锁必问"）；清单非空 = `PROTECTED`。Header 必须常驻白话模式指示。
- **§0.6.3 保护清单**：`.stagent/protection.json`（路径 glob + 白话名称）；首导入规则推荐；Prompt 前置注入；静默合同。
- **§0.6.5 命中行为**：先拦后写 → 一张卡列全部文件 → 同意仅放行卡上清单、清单外再弹补充卡（补充授权计入 ≤2）→ 不同意则一字不写 → 断线/重启保持待审批、**永不自动放行** → 门卫出错/超时按拒绝。
- **§0.2 授权不变式**：未触碰保护清单交互 = 1（合并按钮）；触碰 ≤ 2（是/否 + 合并）；无交集合同**自动批准**。
- **§0.6.4 User-First Discard**：冲突永远以用户主分支为准，不展示 Git 冲突界面。
- **P.1 卡片**：10 条核心目标；PASS 判据含 VIBE/PROTECTED 双模式拦截、零弹窗、撤销一键恢复、四类绕过失败关闭、交互 ≤2、快照失败不开工。
