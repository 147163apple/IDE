## 已拍板的 7 条

### 1. Mock Demo 归宿（原 A2 = B8）
- **标准**: 存入 `.stagent/prototypes/<prototype_id>/`；加入 `.gitignore`，**不合入**用户项目主干源码。
- **理由**: 质询对照与感官复看需要保留；即弃会丢参照；进主干会污染 `package.json` 等业务树。

### 2. 执行凭证校验（原 A1 = B5）
- **标准**: **内存级轻量 Token + 本地 IPC / Domain Socket 实时校验**（Daemon 权威；Gateway 每次敏感操作询问或等价本地校验）。
- **不采用（v0.1）**: 纯离线 JWT 验签作为唯一撤销通道（Abort / 吊销延迟不可接受）。
- **理由**: 微秒级拦截 + Abort 后下一跳即可物理失效。

### 3. 越界处置（原 B7）
- **标准**: Gateway 检出 `E_OUT_OF_SCOPE` / `E_OUT_OF_SCOPE_UNTRACKED`（及保护否决）时：**阻断当次 IO** + **暂停任务并保留现场**（Daemon 置 `PAUSED`）+ **向用户告警**，由用户选择扩权或回滚。
- **禁止**: 静默放行；默认 `kill -9` 整树（除非用户显式选择终止或安全策略另立卡规定）。
- **与定稿关系**: 落实 Supervisor「Gateway 拦越界、不静默放行」。

### 4. 澄清轮次（原 A3）
- **标准**: 主动澄清 **≤ 2 轮**；每题为带 **唯一推荐项** 的白话选择题；未决细项用**安全默认**写入白话合同供一键确认。
- **禁止**: 无休止开放式追问、技术填空卷。
- **与定稿关系**: 收紧 Supervisor「目标 ≤2 轮」为硬顶。

### 5. 拒约 / 改细节回退（原 A4）
- **标准**: 默认**保留** Demo 与会话上下文继续改；仅业务流程大改或 Scope 剧烈扩散时重跑只读影响分析 / 重做 Demo。
- **版本**: 合同草案按草稿递增（如 `v1.0-draft` → `v1.1-draft`）；用户签署前旧草案作废或标记 superseded。
- **与定稿关系**: 对齐《核心资产治理》轻改 / 重签 / 新轮次；版本号细则以本条为准。

### 6. 断线重连状态对齐（原 B6）
- **标准**: 状态推送带单调递增 `epoch` + `sequence_id`；重连时前端上报最后 `sequence_id`；Daemon 下发 **全量快照 + 增量补丁**（Snapshot + Delta）。
- **范围**: 保证展示态（含施工图）重连后可对齐；具体事件名以立卡时 Schema 为准。

### 7. 无 Git 审计降级（原 B9 = C13）
- **标准**: 无法依赖完整 Git 时，使用侧车清单 `.stagent/metadata/audit-manifest.json`，记录相关文件 **SHA-256** 与合同 Hash，作为 Trailer 缺失时的对等降级审计链。
- **原则**: v0.1 先确定性可追溯，不追求额外密码学炫技。
