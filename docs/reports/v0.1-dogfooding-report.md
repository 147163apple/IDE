# Stagent v0.1 自举（Dogfooding）演练报告

> 日期：2026-10-19 · 执行环境：macOS 14 (arm64) / Node v22.22.2 / Git 2.54.0
> 目的：用 Stagent 自身的「合同 → 审批 → Worktree 执行 → 验证 → Evidence → Squash-Merge」链路，完成一次对本仓库副本的真实变更。

---

## 1. 演练方式

1. 将本仓库（不含 `node_modules` / `.output` / 缓存）复制到临时目录并 `git init`，建立基线提交；
2. 通过 `ContractStore` 写入一份真实合同：`writablePaths=["docs/**"]`，验证命令为 `node -e "…existsSync('docs/DOGFOOD-NOTE.md')…"`；
3. `ContractOrchestrator.approve()` 创建真实 Worktree；
4. 在 Worktree 内写入 `docs/DOGFOOD-NOTE.md`；
5. `ContractOrchestrator.execute()` 执行真实验证命令 → 生成 Evidence；
6. `squashMerge()` 执行 `git merge --squash` + Trailer 提交 + 清理 Worktree。

## 4. 未覆盖项（必须如实声明）

1. **AI Worker 真实模型调用未在本次演练中执行**：环境无 API Key。Worker 的越权整批拒绝、预算预检已由 `tests/daemon/ai-worker.test.ts`（5 用例）覆盖，但「真实模型生成代码 → 合并」尚未做过一次真机验证。
2. **架构雷达 1000 节点 60 FPS 未实测**：无头环境无帧率指标；仅完成布局降级与动画关闭的工程缓解。
3. **未在第三方真实项目上试用**：本次为自身仓库副本，非外部用户项目。
4. **单任务串行**：Daemon 当前仅维护一个活跃 Worktree 监听器，未验证多任务并发。
5. **跨平台**：仅 macOS 实测；CI 矩阵配置了 Linux/Windows，但尚未实际跑过远端 CI。

## 5. 演练中发现并修复的缺陷

| #   | 缺陷                                                                                                     | 修复                                                                              |
| --- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 1   | Worktree 改动未提交，`git merge --squash` 报 `nothing to commit`，Evidence 的 `task_commit_sha` 恒为基线 | `execute()` 在验证前执行 `git add -A && git commit`，固化任务分支                 |
| 2   | 结构化命令被网关重新拼接为字符串后再做 shell 注入校验，`node -e "a;b"` 被误拒                            | 命令执行器支持原生 `argv` 路径（`shell:false`），网关优先使用 `{executable,args}` |
| 3   | 崩溃恢复采集 Patch 时未跟踪文件不进入 diff                                                               | 恢复前执行 `git add -A -N`（intent-to-add）再 `git diff HEAD`                     |

---

## 6. 结论

在本仓库副本上，Stagent 的 **合同 → 审批 → 隔离执行 → 真实命令验证 → Evidence → 人工核销 → Squash-Merge → 现场清理** 全链路可复现、可追溯、可回滚，耗时 284ms，Trailer 与存证完整。

但按 §10.1 的严格口径，v0.1 **尚不能标记为「可供目标用户试用」**：AI Worker 真机调用、外部项目试用、跨平台 CI、雷达帧率四项仍未闭环。建议在发布说明中明确以上限制，不得表述为「已验证的生产安全产品」。
