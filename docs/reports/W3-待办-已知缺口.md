## 2. 终端脱敏补多行 PRIVATE KEY 块

当前 `redactSecrets` 只按单行模式遮蔽（含 `KEY=value`、JSON `"api_key": "…"`）。
PEM 私钥是多行块，单行规则会漏掉中间行：

```
-----BEGIN PRIVATE KEY-----
<base64 多行>
-----END PRIVATE KEY-----
```

- [ ] 在 `onLine` 发射前按「块」处理：识别 BEGIN/END 标记，块内所有行替换为 `[REDACTED]`（保留首尾标记或整体替换，需定文案）；
- [ ] 处理跨 chunk 的块边界（行缓冲已具备，需状态机）；
- [ ] 负向用例：多行私钥经 `console.log` 输出后，任何一行都不包含 base64 片段。

当前落在外层 `catch` 里返回 400，但错误文案不可控，且不同端点行为不一致。
